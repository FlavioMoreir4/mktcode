# Portfolio System – MKT Code

This document explains how the portfolio system was designed.

---

## Goal

The portfolio is not a static page. It is a structured system designed to present real technical projects with clear descriptions and scalable architecture.

---

## Features

- Structured project pages
- Technology tags
- Project types (ERP, SaaS, CRM, etc.)
- Featured projects
- SEO‑friendly project URLs

---

## Architecture

The portfolio follows a domain‑oriented architecture.

### Domain
Project entity and rules.

### Application
Commands and queries related to portfolio projects.

### Infrastructure
Persistence and SEO integration.

### Interfaces
Controllers and pages.

---

## Result

The portfolio behaves like a real product showcase system rather than a static page.

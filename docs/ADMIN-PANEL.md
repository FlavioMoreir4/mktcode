# Admin Panel – MKT Code

This document explains how the admin panel works and how it integrates with the rest of the system.

---

## Technology

The admin panel was built using Filament.

---

## Goal

The goal of the admin panel is not just content editing, but to act as the control center of the entire platform.

---

## Managed Content

The admin panel manages:

- Blog posts
- Portfolio projects
- Users
- SEO data
- Content visibility

---

## Architecture Integration

The admin panel does not bypass the architecture.

Instead, it uses:

- Application layer
- Commands
- Domain rules

This ensures that business rules remain consistent.

---

## Result

The admin panel behaves as a real internal system instead of a simple content editor.

# Blog System – MKT Code

This document explains how the blog system was designed and implemented.

---

## Goal

The blog was not created only to publish articles, but to serve as a technical content platform that supports SEO and portfolio positioning.

---

## Main Features

- SEO‑friendly URLs
- Structured post pages
- Clean architecture
- Admin panel integration (Filament)
- Dynamic meta tags

---

## Architecture

The blog system follows the same architecture used in the rest of the project.

```
Domain
Application
Infrastructure
Interfaces
```

---

## Why Not a CMS?

Instead of using a CMS, the blog was built as part of the main application to ensure:

- Full control over architecture
- Full control over SEO
- Better performance
- Long‑term scalability

---

## Result

The blog is now a core part of the platform, not just a content section.
